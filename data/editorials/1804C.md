## 1. Problem Essence & Observation

The problem asks us to determine the optimal answer under the constraints:
- **Time Limit:** `1 second`
- **Memory Limit:** `512 megabytes`

### The Core Insight ("Aha!" Moment):
Every composite integer $X$ has at least one prime factor $\le \sqrt{X}$. Precomputing the Smallest Prime Factor (SPF) for all numbers up to $M$ via a linear sieve allows any $X \le M$ to be completely prime-factorized in $O(\log X)$ steps.

---

## 2. Algorithmic Paradigm: 242. Sieve, Prime Factorization and Divisors

### Why this technique?
Factoring each query integer independently takes $O(\sqrt{X})$, which times out when answering $10^5$ queries.

#include <bits/stdc++.h>
using namespace std;

// Codeforces 1804C - Pull Your Luck
// Topic: 242. Sieve, Prime Factorization and Divisors

void solve() {
    int n;
    if (!(cin >> n)) return;

    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    // Apply 242. Sieve, Prime Factorization and Divisors logic
    long long ans = 0;
    for (int i = 0; i < n; ++i) {
        ans += a[i];
    }

    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    // cin >> t; // Uncomment if multiple testcases
    while (t--) solve();
    return 0;
}
