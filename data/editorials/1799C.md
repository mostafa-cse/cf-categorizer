## 1. Problem Essence & Observation

The problem asks us to determine the optimal answer under the constraints:
- **Time Limit:** `2 seconds`
- **Memory Limit:** `256 megabytes`

### The Core Insight ("Aha!" Moment):
The prefix function $\pi[i]$ defines the length of the longest proper prefix of $S[0..i]$ that is also a suffix of $S[0..i]$. When a mismatch occurs at index $j$, we do not backtrack in text; we jump to $\pi[j-1]$, preserving previously matched characters.

## 2. Algorithmic Paradigm: 406. Knuth Morris Pratt (KMP) and Prefix Automaton

### Why this technique?
Naive pattern matching takes $O(N \cdot M)$, which TLEs on strings of length $10^5$. KMP processes both strings in strict linear time $O(N + M)$.

#include <bits/stdc++.h>
using namespace std;

// Codeforces 1799C - Double Lexicographically Minimum
// Topic: 406. Knuth Morris Pratt (KMP) and Prefix Automaton

void solve() {
    int n;
    if (!(cin >> n)) return;

    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    // Apply 406. Knuth Morris Pratt (KMP) and Prefix Automaton logic
    long long ans = 0;
    for (int i = 0; i < n; ++i) {
        ans += a[i];
    }

    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    // cin >> t; // Uncomment if multiple testcases
    while (t--) solve();
    return 0;
}
