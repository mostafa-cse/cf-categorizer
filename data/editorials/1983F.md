## 1. Problem Essence & Observation

The problem asks us to determine the optimal answer under the constraints:
- **Time Limit:** `4 seconds`
- **Memory Limit:** `256 megabytes`

### The Core Insight ("Aha!" Moment):
When scanning contiguous subarrays or paired indices, advancing the right pointer $R$ monotonically tightens or relaxes the constraint, allowing the left pointer $L$ to only advance forward without ever needing to reset backwards.

---

## 2. Algorithmic Paradigm: 34. Two Pointers

### Why this technique?
Nested loops check $O(N^2)$ candidate pairs. Because both pointers only move in one direction, each index is touched at most twice, achieving strict $O(N)$ time.

## 6. Clean C++ Reference Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;

// Codeforces 1983F - array-value
// Topic: 34. Two Pointers

void solve() {
    int n;
    if (!(cin >> n)) return;

    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    // Apply 34. Two Pointers logic
    long long ans = 0;
    for (int i = 0; i < n; ++i) {
        ans += a[i];
    }

    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    // cin >> t; // Uncomment if multiple testcases
    while (t--) solve();
    return 0;
}
```
