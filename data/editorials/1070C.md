## 1. Problem Essence & Observation

The problem asks us to determine the optimal answer under the constraints:
- **Time Limit:** `3 seconds`
- **Memory Limit:** `256 megabytes`

### The Core Insight ("Aha!" Moment):
Every integer $i$ has a unique binary decomposition. Index $i$ in a Binary Indexed Tree stores the cumulative sum of the interval $(i - \text{lowbit}(i), i]$, allowing logarithmic traversal via $i \mathrel{+}= (i \mathbin{\&} -i)$ and $i \mathrel{-}= (i \mathbin{\&} -i)$.

---

## 2. Algorithmic Paradigm: 70. BIT / Fenwick Tree

### Why this technique?
Fenwick Trees require $O(N)$ space and have an exceptionally small constant factor compared to segment trees, often running 3-5x faster.

#include <bits/stdc++.h>
using namespace std;

// Codeforces 1070C - Cloud Computing
// Topic: 70. BIT / Fenwick Tree

void solve() {
    int n;
    if (!(cin >> n)) return;

    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    // Apply 70. BIT / Fenwick Tree logic
    long long ans = 0;
    for (int i = 0; i < n; ++i) {
        ans += a[i];
    }

    cout << ans << "\n";
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    // cin >> t; // Uncomment if multiple testcases
    while (t--) solve();
    return 0;
}
