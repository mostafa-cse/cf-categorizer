## 1. Problem Essence & Observation

The problem asks us to determine the optimal answer under the constraints:
- **Time Limit:** `2.0s`
- **Memory Limit:** `256MB`

### The Core Insight ("Aha!" Moment):
Because all edge weights are non-negative, the shortest distance to the unvisited vertex with the minimum tentative distance is finalized and cannot be decreased by further transitions (greedy choice property).

---

## 2. Algorithmic Paradigm: 168. Dijkstra's Algorithm

### Why this technique?
BFS only works on unweighted graphs; Bellman-Ford takes $O(V \cdot E)$. Dijkstra with a priority queue executes in $O((V + E) \log V)$.

---

## 3. Step-by-Step Solution Walkthrough

### Step 1: Graph Modeling
Construct an adjacency list with pairs $(v, w)$ for each directed or undirected edge from $u$ to $v$ with weight $w \ge 0$.

### Step 2: Distance Table Initialization
Initialize $dist[v] = \infty$ for all vertices, with $dist[\text{source}] = 0$.
Push $(0, \text{source})$ into a min-priority queue `std::priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>>`.

### Step 3: Relaxation Loop
While the priority queue is not empty:
1. Pop $(d, u)$. If $d > dist[u]$, discard (stale entry).
2. For each neighbor $(v, w)$ of $u$:
   If $dist[u] + w < dist[v]$:
   $$dist[v] = dist[u] + w$$
   Push $(dist[v], v)$ into the priority queue.

---

## 4. Edge Cases & Corner Cases

- Unreachable target vertices ($dist[v] = \infty$).
- Multiple edges between the same pair of vertices or self-loops.
- Accumulating distances exceeding $2^{31}-1$.

---

## 5. Complexity Analysis

- **Time Complexity:** $\mathcal{O}((V + E) \log V)$
  Every vertex is extracted from the priority queue at most once. For every edge, we perform at most one priority queue push operation taking $\mathcal{O}(\log V)$.
- **Space Complexity:** $\mathcal{O}(V + E)$
  Required for storing the adjacency list and the distance array.

## 6. Clean C++ Reference Implementation

```cpp
#include <bits/stdc++.h>
using namespace std;

// Codeforces gym_100122_E - Рыцари
// Topic: 168. Dijkstra's Algorithm

const long long INF = 1e18;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    if (!(cin >> n >> m)) return 0;

    vector<vector<pair<int, long long>>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v; long long w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});
    }

    priority_queue<pair<long long, int>, vector<pair<long long, int>>, greater<>> pq;
    vector<long long> dist(n + 1, INF);

    dist[1] = 0;
    pq.push({0, 1});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        if (d > dist[u]) continue;

        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }

    for (int i = 1; i <= n; ++i) {
        cout << (dist[i] == INF ? -1 : dist[i]) << (i == n ? "" : " ");
    }
    cout << "\n";
    return 0;
}
```
